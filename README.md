# Calabash Lab 创业看板

夫妻档创业任务看板：分职能、看进度、标卡点、自动提醒、奖励机制。
手机可装成 App，两人实时同步（接 Supabase 后）。

## 本地预览（不填任何密钥）
直接用浏览器打开 `index.html` 即可。数据存在本机 localStorage，仅本机可见。
手机预览：在本文件夹运行 `python3 -m http.server 8000`，手机连同一 WiFi 访问 `http://<你Mac的局域网IP>:8000`。

## 接入云端（两人实时同步）
1. 在 https://supabase.com 新建项目。
2. 打开 SQL Editor，粘贴 `schema.sql` 全部内容并执行。
3. Settings → API，复制 Project URL 和 anon public key。
4. 填入 `config.js` 的两个占位符。
   - anon key 是公开安全的，可写前端；service_role key 千万别放这。
5. 重新打开页面，即变为云端同步模式。

## 免费上线（GitHub Pages）
1. 新建一个 GitHub 仓库，把本文件夹全部文件推上去。
2. 仓库 Settings → Pages → Source 选 `main` 分支 / `(root)` → Save。
3. 几分钟后获得 `https://<用户名>.github.io/<仓库名>/` 网址。
4. 手机浏览器打开 → 分享/添加到主屏幕 → 变成手机 App。

## 使用节奏
- 每周例会：从「待分配池」点「认领」→ 设 owner/截止 → 进「本周进行中」。
- 周中：拖动进度条、改状态，系统周三起提醒未更新的人。
- 下周例会：复盘，「已完成」累计创业币，里程碑点亮即共同兑现奖励。
- 「生成本轮集市任务」：一键生成集市 5 环节到待分配池。

## 奖励机制（协作型，避免夫妻竞争）
- 创业币：每完成 1 个任务 +1，共同池，满阈值一起兑现。
- 里程碑：SKU体系上线 / 社媒破粉 / 网站上线，各对应一次共同奖励。
- 连续推进：每人连续有更新的周数，断了他不罚只重置。
